# Salesforce Permission Manager

A VS Code extension for managing Salesforce Profile and Permission Set permissions in bulk.

## Features

- Update Field Permissions
- Update Object Permissions
- Update Tab Permissions
- Update Layout Assignments
- Update Record Type Visibility
- Update Custom Permissions
- Bulk update multiple Profiles
- Bulk update multiple Permission Sets

## Usage

1. Open your Salesforce project in VS Code.
2. Run `Permission Manager`.
3. Select the folder containing your Profiles or Permission Sets.
4. Select the metadata files to update.
5. Choose the permissions you want to apply.
6. The extension updates the metadata XML files automatically.
